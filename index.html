Sentence templates

The built-in templates are grouped by real conversational function and use dedicated Punjabi grammar rules for agreement, questions, negation and word order. Probability controls how often each enabled pattern appears; the values are normalised automatically.

Add a new template

Click slot types in order to build the sentence pattern. VERB (simple) conjugates a plain verb to the subject; VERB (wants to…) uses a "want"-style verb plus a compatible action.

Using this app on iPhone

If controls are inactive inside a file preview, open the hosted app directly in Safari. A preview that blocks JavaScript cannot run the app. Once hosted, use Safari’s Share menu to add the site to your Home Screen. Preferences and saved sentences belong to the browser/site where you saved them.
